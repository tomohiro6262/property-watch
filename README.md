# 物件アラート

居住用の中古マンション・中古戸建を SUUMO から毎日集め、条件で判定して、毎朝 Gmail で配信する仕組みです。
Claude Code の定期実行ルーチン（クラウド）で毎朝 6:40 に動きます。

## 処理の流れ

| 順番 | ファイル | 内容 |
|---|---|---|
| 1 | `collect_suumo.py` | SUUMO の検索条件つき RSS から物件を集める（1フィード30件上限のため価格帯で分割） |
| 2 | `screen.py` | 価格・間取り・築年数・面積で絞り込み、通勤時間と詳細ページ（権利・接道・駐車場・管理費など）で判定・採点 |
| 3 | `commute.py` | 最寄駅 → 日本橋・溜池山王の平日 8:50 着の所要時間を Yahoo!路線情報で調べて保存 |
| 4 | `hazard.py` | 国土地理院「重ねるハザードマップ」で洪水・高潮の浸水深と土砂災害警戒区域を判定 |
| 5 | `make_digest.py` | 前回との差分（新着・値下げ）と候補ランキングの配信メールを作る |
| - | `run_daily.py` | 1〜5 をまとめて実行し、古いデータを削除する |

外部ライブラリは使っていません（Python 標準ライブラリのみ）。

## 条件（2026年9月時点）

- エリア：東京23区・三鷹市・立川市・妙典駅・和光市駅・溝の口駅
- 種別：中古戸建・中古マンション／検索上限 8,000万円（目安 5,500〜6,500万円、超える分は別枠）
- 3LDK以上・築15年以内・駅徒歩10分以内
- 戸建：土地50㎡以上・建物80㎡以上・駐車場必須。2階建ては加点、私道・擁壁2m以上は減点
- マンション：専有65㎡以上。管理費＋修繕積立金 月4万円超・1階・北向き・総戸数20戸未満は減点
- 通勤：日本橋・溜池山王の両方へドアtoドア60分以内（50分以内は加点）
- 除外：借地権・再建築不可・告知事項あり・賃貸中・前面道路4m未満・建て替えに許可が必要な道路・土砂災害警戒区域

## データ

`data/` は前回との差分を取るための状態です。ルーチンが毎日 `claude/property-data` ブランチに保存します。

- `suumo_YYYYMMDD.json`：収集した物件（直近3日分）
- `result_YYYYMMDD.json`：判定結果（直近3日分）
- `digest_YYYYMMDD.html / .txt`：配信メール（直近3日分）
- `station_times.json`：駅ごとの通勤時間
- `details/*.json`：物件ごとの詳細とハザード判定（掲載終了で削除）

## 手動で実行する場合

```
python run_daily.py
```
